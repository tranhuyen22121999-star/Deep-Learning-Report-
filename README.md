# Fashion-MNIST CNN Project

This project trains and evaluates image classifiers for the Fashion-MNIST dataset with PyTorch. The main deliverable is the executed notebook `Practice 1.ipynb`, which includes data preparation, EDA, an MLP baseline, a CNN experiment, checkpoint selection, test evaluation, ROC/PR curves, confusion-matrix analysis, and misclassified examples.

## Project Contents

- `Practice 1.ipynb` - Main notebook and report.
- `fashion_cnn_model.pth` - CNN `state_dict` checkpoint selected using the best validation accuracy.
- `model_performance_summary.csv` - Per-class test metrics generated by the notebook.
- `data/FashionMNIST/` - Downloaded Fashion-MNIST files.

## Usage

### Install dependencies

```bash
pip install torch torchvision numpy pandas matplotlib seaborn scikit-learn pillow
```

### Run the notebook

```bash
jupyter notebook "Practice 1.ipynb"
```

Run the cells from top to bottom. The notebook downloads Fashion-MNIST if it is not already present, trains the models, restores the best CNN checkpoint, evaluates it once on the test set, and writes `model_performance_summary.csv`.

## Current results

With the recorded seed and the current configuration, the CNN reaches approximately 90% test accuracy. The most difficult class is `Shirt`, which is frequently confused with `T-shirt/top`, `Pullover`, and `Coat`. These classes are visually similar at the original 28x28 resolution.
